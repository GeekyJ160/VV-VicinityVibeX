# Vicinity Vibe

A culture-first way to find people nearby in Dallas–Fort Worth. You show up as a frequency. People see your neighborhood, never a pin.

## Run

```bash
npm install
npm run dev
```

The app listens on `0.0.0.0:8080`. Create an account with email, set Vibe DNA, then Spark people in Discover.

## Checks

```bash
npm test
npm run typecheck
npm run build
```
